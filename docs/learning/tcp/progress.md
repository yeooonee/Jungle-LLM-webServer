# TCP 학습 진행

- 현재 단계: 기본 개념 학습 후 최소 TCP 에코 서버 구현.
- 사용자 경계: 개념을 함께 배우고, 명시적으로 지시한 범위만 구현. 이번에 문서화와 구현을 요청함.
- 사용자 설명으로 확인: 리스닝 소켓 종료의 영향, 수신 재호출, 줄바꿈 경계의 미완성 데이터 보관, 단일 스레드의 대기, 외부 접속용 바인딩, 부분 송신 위치 계산.
- 도움을 받아 보충: TCP 메시지 경계 없음, 수신 버퍼 포화 시 흐름 제어, 패킷 손실 재전송, connect/accept 구분, half-close, 로컬 errno.
- 구현 범위: 포트 CLI, IPv4 순차 에코, 부분 송수신, 오류/시그널 처리. 코치가 구현했으므로 사용자 독립 구현으로 기록하지 않음.
- 검증 관찰: macOS에서 debug/release/ASan+UBSan 빌드 성공. debug와 sanitizer 바이너리의 TCP 통합 테스트 통과. Linux 실행, 패킷 캡처, 부하 테스트, 별도 누수 검사는 수행하지 않음.
- 아직 미확인: 사용자 자신의 코드 설명, 직접 실행 관찰, 오류 처리와 흐름 제어의 독립 적용.
- 다음 한 가지: main → 리스닝 소켓 생성 경로를 사용자가 읽고 설명. 사용자의 진행 지시에 따라 이어감.
